# btc-options-lab

Research platform for BTC options on Deribit: a 24/7 market-data recorder, Black-76 pricing on a
fitted volatility surface, backtests of a fixed-rule credit-spread strategy, paper trading on
Deribit testnet, and a read-only Streamlit dashboard.

Work in progress: the build plan is in `docs/brief.md` and the status in `docs/progress.md`.
The full README (architecture, setup, results, credits) comes with release v1.0.

Paper-trading research project, not investment advice.
